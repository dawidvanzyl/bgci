# .design

Design mockups for UI stories. Rules:

- Every story that touches the UI cites at least one mockup from this folder in its
  `Design reference` bullet.
- The mockup is authoritative. Where it and the story text disagree, the mockup governs.
- Any tool may produce the mockup (HTML, PNG, SVG). Name it after the story or epic, for
  example `epic-m1-expansion-tab.html`.
- Mockups follow `docs/design-standards.md`.
